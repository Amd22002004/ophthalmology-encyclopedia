# Добавить клинику

Добавляет клинику без неподтверждённых юридических данных и связей.

1. Прочитайте `docs/architecture/clinics.md`, `graph-model.md` и фактическую schema.
2. Проверьте юридические и контактные данные по материалам задачи; не заполняйте
   неподтверждённые поля.
3. Создайте только подтверждённые прямые связи с врачами, оборудованием, процедурами,
   заболеваниями, поставщиками и специальностями через `knowledge-graph`.
4. Проверьте каталог, страницу клиники и обратные страницы сущностей.
5. Примените `medical-seo` к новому публичному маршруту.
6. Если потребовалось изменение модели, сначала выполните `project-architecture` и
   `prisma-schema-safety`, затем `documentation-maintenance`.
