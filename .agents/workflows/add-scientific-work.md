# Добавить научную работу

Добавляет подтверждённую научную работу врачу без смешения с редакционной публикацией.

1. Прочитайте `docs/architecture/publications.md`, `doctors.md`, `graph-model.md` и schema.
2. Установите владельца: `ScientificWork` допустима только с врачом из системы;
   редакционный материал создавайте как `Publication`.
3. Добавьте подтверждённые локальные PDF и структурированные данные без копии в
   другой модели.
4. Создайте только тематические связи с Disease и Procedure через `knowledge-graph`.
5. Проверьте страницу врача, каталог публикаций, обратные блоки и SEO.
6. При изменении архитектурного контракта завершите `documentation-maintenance`.
