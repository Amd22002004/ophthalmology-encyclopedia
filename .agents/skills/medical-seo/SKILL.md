# Медицинское SEO

## Обязательное чтение

Прочитайте подходящий документ сущности в [`docs/architecture/`](../../../docs/architecture/),
[`design-principles.md`](../../../docs/architecture/design-principles.md), текущие
[`src/lib/seo.ts`](../../../src/lib/seo.ts),
[`src/components/seo/schema-org.tsx`](../../../src/components/seo/schema-org.tsx)
и [`src/app/sitemap.ts`](../../../src/app/sitemap.ts).

## Алгоритм

1. Установите владельца страницы и её канонический маршрут; не создавайте дублирующую
   SEO-витрину вместо сущности графа.
2. Составьте title и description только из подтверждённых данных страницы.
3. Добавьте canonical и OpenGraph через существующие SEO-утилиты, а не локальным
   повторением метатегов.
4. Выберите Schema.org-тип по модели страницы и переиспользуйте существующие
   JSON-LD-компоненты. Не публикуйте свойства, которых нет в источниках.
5. Добавьте двусторонние внутренние ссылки только для достоверных отношений графа.
6. Включите публичный маршрут в sitemap и проверьте SSR metadata в готовой странице.
7. Запустите build и проверьте, что canonical, JSON-LD и ссылки не содержат
   технических имён или несуществующих URL.
